# Source notes

The team’s pitch presentation cited the following sources for background on metal additive manufacturing and LPBF post-processing. Exact page or report versions were not included in the supplied project archive, so these are recorded as presentation references rather than independently verified project data.

- [AMPOWER](https://www.ampower.eu)
- [GE Additive](https://www.ge.com/additive)
- [ExOne](https://www.exone.com)
- [EOS](https://www.eos.info/en)
- [ASTM F3303-18](https://www.astm.org/f3303-18.html)
- [NIOSH](https://www.cdc.gov/niosh)

The original pitch included estimated comparisons for labor, cycle time, safety risk, and cost. Those estimates are not reproduced as achieved results in this repository because no supporting test records, calculation sheets, or measurement data were supplied.
